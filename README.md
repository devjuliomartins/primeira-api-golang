# Primeira API em Golang com Gin

Este repositório contém minha primeira experiência desenvolvendo uma API utilizando Golang e o framework Gin. Eu criei essa API como parte do meu aprendizado em desenvolvimento de APIs e para entender como elas funcionam, desde a criação até o envio para o GitHub.

## Por que esse projeto?

Esse projeto foi um marco no meu aprendizado de programação e desenvolvimento de software. Foi o meu primeiro contato com o desenvolvimento de APIs, e eu quis documentar esse momento e compartilhar com outras pessoas.

## O que a API faz?

Essa API é um simples exemplo de "Hello, World!" criado com o framework **Gin** em Golang. Como foi o meu primeiro contato com o desenvolvimento de APIs, o objetivo desse projeto foi entender os conceitos fundamentais, como a criação de rotas, o envio de respostas e o funcionamento básico de uma API.

A API não realiza nenhuma operação complexa, ela apenas responde com a mensagem "Hello, World!" quando você acessa o endpoint principal.

Este projeto foi uma maneira de aprender o processo de criação de uma API e, ao mesmo tempo, praticar o uso do Git e GitHub.
